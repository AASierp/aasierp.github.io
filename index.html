Projects I'm Particularly Proud Of:

Real Estate Scrape

Real Estate Scrape is a web application designed to collect, store, and display real estate listing data using automated scraping techniques. Built with ASP.NET MVC, the project uses HTML Agility Pack to scrape structured data from property websites and stores the results in a local SQLite database using Entity Framework Core for data access and management.

The scraper collects information such as listing prices, addresses, square footage, and number of bedrooms. That data is parsed from HTML content and normalized before being stored. Users can view and search listings directly through the web app, which features a clean and functional interface built with ASP.NET MVC.

Key Technologies Used:

  • C# / .NET Core – Core application logic
  • HTML Agility Pack – DOM parsing and web scraping
  • Entity Framework Core – ORM for SQLite database operations
  • SQLite – Lightweight, file-based data storage
  • ASP.NET MVC – Web app structure and frontend presentation

Challenges Solved:

  • Parsing irregular and inconsistent HTML layouts
  • Managing relational data in a lightweight SQLite environment
  • Designing a maintainable, testable architecture in a full-stack .NET setting

Why It Matters:

This project was a great opportunity to apply backend and data-access principles in a real-world scenario, and it reflects my interest in building robust, data-driven applications with clean architecture and a focus on clarity.

Time Sheet Filter

Timesheet Filter is a C# WinForms application designed to analyze and filter employee clock-in/clock-out data from Excel spreadsheets. The goal was to streamline the review of timekeeping records and automatically flag entries that violate company policies—reducing manual effort and improving accuracy.

The application uses the ClosedXML library to read and write Excel files without needing Excel installed. It loads raw timesheet data in the background, displays it in a clean WinForms interface, and applies business rules to filter out non-compliant records.

Key Filtering Features:

  • Long lunches: Flags entries where lunch exceeds 30 minutes and 59 seconds.
  • Extended breaks: Flags breaks longer than 20 minutes and 59 seconds.
  • "Incidental" time: Flags employees whose cumulative incidental time exceeds 10 minutes.
  • First "Ready" entry: Keeps only the first “Ready” status per employee per day to reduce noise.

Technologies Used:

  • C# / .NET Framework
  • WinForms for the user interface
  • ClosedXML for Excel file handling
  • Custom filtering logic based on real-world HR timekeeping policies

Why It Matters:

This project demonstrates the ability to work with structured data, design user-friendly tools, and implement precise business rules with confidence. It reflects my interest in backend logic, automation, and practical problem-solving—skills I aim to bring into a professional development role.
